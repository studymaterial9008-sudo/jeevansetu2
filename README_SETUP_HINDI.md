# JeevanSetu — College Demo Setup

## Files
- `index.html` — main JeevanSetu app
- `firebase-config.js` — Firebase Web App configuration
- `firestore.rules` — Firestore security rules for the demo
- `README_SETUP_HINDI.md` — setup notes

## GitHub Pages
Upload all 4 files directly into the repository root. Keep `index.html` and `firebase-config.js` in the same folder.

## Firebase
Authentication: Email/Password enabled.
Firestore: database `(default)` created and the included rules published.

This is a college/demo prototype. Use dummy data only; do not enter real patient medical information.
